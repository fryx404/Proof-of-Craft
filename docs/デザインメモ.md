## 1. デザインシステム "fryx404 Pop"

配色は個人サイト（https://fryx404.github.io/）と揃えた「ポップ＆サイバー」路線。

| | ライト | ダーク |
|---|---|---|
| Background | `#FFFFFF` | `#000000`（OLED向けの真っ黒） |
| Surface | `#FFFFFF` | `#1A1A1A` |
| Primary | `#00D1FF` Electric Cyan | 同じ |
| Accent | `#FFD600` Sunshine Yellow | 同じ |
| Text | `#2D3436` Charcoal | `#F5F5F5` |

原則:

- **角丸 16px**（モーダルのみ 22px）— 大きめの角丸でフレンドリーな印象にする
- **シャドウ** — ライトはシアンを帯びた薄いドロップシャドウ、ダークは不透明度を抑えた微弱なシャドウ（浮遊感のみ）
- **書体** — 見出しは Outfit（SemiBold 600 / Bold 700）、本文は Zen Kaku Gothic New、コードは JetBrains Mono
- **アイコン** — 線画（Lucide系）を `stroke-width: 2.5` で統一

## 2. 色を変える — 触るのは1箇所だけ

色は `assets/style.css` 冒頭の**カラートークンブロックだけ**で定義しています。
そこから下ではカラーコードを一切書かず `var(--*)` しか使っていないので、
**トークンの値を書き換えれば全体が追従します**。個別のセレクタを探して回る必要はありません。

```css
:root, [data-theme="light"] {
  --primary: #00D1FF;   /* ← ここを変えるとボタン・枠・影・タグが全部変わる */
  --accent:  #FFD600;
}
[data-theme="dark"] { ... }
```

新しくカラーコードを直接書きたくなったら、まずトークンとして追加できないか検討すること。
**ハードコードを1つ入れた時点で、テーマ切替がその箇所だけ壊れます。**

### `--primary-ink` が別にある理由

`#00D1FF` を白背景の文字色に使うと、コントラスト比が **1.7:1** しかなく読めません。
そのため「白地に文字として置くための暗いシアン」を `--primary-ink`（`#007A96`, 4.9:1）として分けています。

- `--primary` … 面・枠線・影に使う（背景として）
- `--primary-ink` … 文字・アイコンに使う（前景として）

ダークモードでは黒地なので `--primary-ink` も `#00D1FF` のままです。
`--primary` を変えたときは `--primary-ink` も合わせて暗めの同系色にしてください（AA基準は 4.5:1）。
`--accent` と `--accent-ink` も同じ関係です。

## 3. テーマ切替（ライト / ダーク / システム連動）

- 画面右上のスイッチで切り替え、選択は `localStorage`（キー `poc-theme`）に保存
- `system` を選ぶと OS の設定に追従し、OS側を変えた瞬間に反映される
- 実体は `<html data-theme="light|dark">` の属性切り替えだけ
- ロジックは `index.html` 内のインラインスクリプト（`app.js` ではない）

**`<head>` 先頭のスクリプトを消さないこと。** CSS 適用前にテーマを確定させています。
これが無いと、ダークモードでリロードするたびに一瞬白く光ります。

## 4. 文言・書体・余白を変える

| 変えたいもの | 場所 |
|---|---|
| 見出し下の2行（思想の文） | `tools.json` の `site.lead`（`<br>` で改行可） |
| ページタイトル | `tools.json` の `site.title` |
| 見出し `Tool Archive` の文字列 | `index.html` の `.hero__title` |
| 見出しの大きさ | `style.css` `.hero__title` の `clamp()` の**第3引数** |
| 見出しの太さ | `style.css` `.hero__title` の `font-weight`（現在 600） |
| 見出し周りの余白 | `style.css` `.hero` の `padding`（現在 上112px / 下56px） |
| 書体 | `style.css` 冒頭の `--font-en` / `--font-ja` / `--font-mono` |
| アクセント色 | `style.css` 冒頭の `--primary` / `--accent` |
| フッターの著作権表示 | `index.html` の `.site-footer__copy` |

`font-weight` を変えるときは、`index.html` の Google Fonts の URL に
そのウェイトが含まれているか確認すること（現在 Outfit は 600 / 700 / 800 のみ読み込み）。
含まれていないウェイトを指定すると、ブラウザが勝手に太らせて汚くなります。

| キー | 必須 | 説明 |
|---|---|---|

| `name` | ● | ツール名 |
| `nameJa` | | 日本語名 |
| `date` | ● | `YYYY-MM`。並び順に使用 |
| `version` | | バージョン表記 |
| `tags` | ● | 配列。色は自動で割り当てられる |
| `summary` | ● | カードの短い説明 |
| `description` | | モーダルの本文 |
| `image` | | サムネイル。GitHub の raw URL でOK |
| `repo` / `download` | | ボタンのリンク先 |
| `requirements` / `install` / `usage` / `notes` | | 配列。空なら見出しごと非表示 |
| `code` | | 起動用コードブロック。`\n` で改行 |

### 画像

GitHub リポジトリの raw URL をそのまま指定できます。
形式: `https://raw.githubusercontent.com/fryx404/<repo>/main/images/sample.gif`

ローカルに置きたい場合は `assets/img/` を作って `"image": "./assets/img/xxx.gif"` とします。

### タグの色

`assets/app.js` の `TAG_COLORS` で決まります。ここに無いタグは名前のハッシュから
自動で 6 色のいずれかが割り当てられるので、**新しいタグを増やしても設定は不要**です
（同じタグ名なら常に同じ色になる）。色を固定したいときだけ 1 行足します。

```js
const TAG_COLORS = {
  maya: 'teal',
  python: 'blue',
  houdini: 'coral',   // ← 追加例
};
```

ただし **画面上の見た目は 3 種類**です。ブランドを 2 色に保つため、
`style.css` 側で 6 クラスを次のように集約しています（JS の仕組みは変えていない）。

| `TAG_COLORS` の値 | 見た目 | 該当タグの例 |
|---|---|---|
| `teal` / `blue` | シアンの塗り | Maya, Python, MEL |
| `purple` / `coral` | イエローの塗り | Rigging, GUI, Modeling, Animation |
| `amber` / `green` | 枠線のみ（無彩色） | Blender, Tool, Utility |

見た目の割り当てを変えたいときは `style.css` の「タグ」ブロックを編集します。

## 6. 実装上の落とし穴

### `hidden` 属性を `display` で潰さないこと

**一度これで踏んだ。** `app.js` は「まだ何も記録されていません」の表示を
`emptyBox.hidden = TOOLS.length > 0` で制御しています。
このとき `.empty` に `display: flex` を直接書くと、ブラウザ標準の `[hidden] { display: none }` を
上書きしてしまい、`hidden` を立てても消えなくなります。

`style.css` の冒頭で以下を宣言して防いでいます。この行は消さないこと。

```css
[hidden] { display: none !important; }
```

新しく `display` を持つ要素を足すときも、この行があるので個別対応は不要です。

### アクセシビリティの前提

- 配色は両テーマとも WCAG 2.1 AA（本文 4.5:1、12px以下の補助テキストは 3:1）を満たしている
- `prefers-reduced-motion: reduce` でアニメーションを全停止
- 先頭に本文へのスキップリンク（Tabキーで出現）

色を変えたときは、上のコントラスト比が崩れていないか確認すること。
特に `--text-faint`（12pxの補助テキスト用）はライトで 3.06:1 と余裕がなく、少し明るくするだけで落ちます。

## 7. 著作権表示

```
© 2025–2026 Takumi Furuya (fryx404)
```

- **起点 2025** — 最初のツールを公開した年。著作権表示は最初の公開年を起点に書くのが原則。
  サイト自体は2026年公開だが、`2026` 単独にすると2025年公開のツールの分が抜け落ちる
- **終点** — `app.js` が現在年を入れるため自動で伸びる。更新していない年まで伸ばしたくない場合は、
  `index.html` の `<span id="year"></span>` を `2026` のような固定値に書き換える（`app.js` は変更不要）
- **"All rights reserved" は外した** — 万国著作権条約の時代の慣習表記で、
  現在のベルヌ条約下では法的な効果がない。残しても害はないので、戻したければ末尾に足すだけ
